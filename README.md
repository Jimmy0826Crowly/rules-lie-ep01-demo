# 《规则在说谎》EP01 互动原型

这是一个零依赖静态网页原型，把第 1 集《开门者活》的 36 个 grid 改成“正式剧情插图 + 对白 + 分镜进度 + 线索选择”的手机试玩体验。

## 打开方式

直接打开：

```text
C:\Users\Jimmy\Desktop\AI游戏\game-ep01-prototype\index.html
```

或在目录里用任意静态服务器打开。

线上分享：

```text
https://jimmy0826crowly.github.io/rules-lie-ep01-demo/
```

## 已覆盖

- EP01 全 36 个分镜节点
- EP01 全 36 幕正式剧情插图：`assets/scenes/ep01-grid01.png` 到 `ep01-grid36.png`
- 角色、场景、道具设定图作为绘制参考，页面不再直接拼贴参考图
- 竖屏漫剧舞台，手机首屏可直接点“继续”
- 底部对白框、继续 / 回看 / 自动播放
- 右侧分镜时间轴
- 线索解锁：发绳、纸条、第二行、开门者活、空城、完好大门
- 两个关键微选择：伪小满敲门、是否相信第二行
